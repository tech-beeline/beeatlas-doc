# BeeAtlas Documentation

Добро пожаловать в портал документации **BeeAtlas** и методологии **ПТР (Проектирование Технического Решения)**.

## Разделы документации

### ПТР — Проектирование технического решения

Методология проектирования технических решений, включающая:

- **Инструменты** — настройка VS Code, Structurizr, GitLab
- **Методология** — проверка входных сведений, контекстные и контейнерные диаграммы, API, модель данных
- **Реестры** — архитектурные решения (ADR), метрики, термины
- **Правила** — моделирование архитектуры, стили, версионирование

[Перейти к ПТР →](start.md)

### BeeAtlas — Система архитектурного моделирования

Документация по системе BeeAtlas:

- **Модели** — ФДМ, технорадар, карты возможностей, каталог приложений, Е2Е сценарии, Каталог паттернов, архитектура компании, аналитический отчёт фитнес-функций
- **База знаний** — архитектурный комитет, техническая политика
- **CX** — библиотеки Customer Journey и Business Interaction
- **Профиль** — заявки, подписки, экспорт

[Перейти к BeeAtlas →](beeatlas-docs/README.md)
