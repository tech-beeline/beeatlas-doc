# Процесс импорта

**Назначение**: Просмотр хода и результатов импортирования данных.

## Возможности

- Просмотр списка пакетов импорта
- Фильтрация пакетов по статусу
- Просмотр частей пакета
- Просмотр содержимого части пакета в формате JSON

## Как использовать

### Просмотр пакетов импорта

1. Перейдите в раздел "Консоль администратора" → "Процесс импорта".
2. При необходимости выберите статус в фильтре «Статусы»: «Все», «Успешно», «С ошибкой», «В обработке» или «Проблемный».
3. Нажмите «Сбросить», чтобы вернуть фильтр в состояние «Все».

### Таблица пакетов

| Колонка | Описание |
|---------|----------|
| **Идентификатор** | Идентификатор пакета; ссылка на страницу частей пакета |
| **Операция** | Тип операции: обновление бизнес-возможностей, технических возможностей или приложений |
| **Дата загрузки** | Дата создания пакета |
| **Обработанные/Все** | Количество успешно обработанных частей и общее количество частей пакета |
| **С ошибкой** | Количество частей, обработанных с ошибкой |
| **В обработке** | Количество частей, обработка которых ещё идёт |
| **Статус** | «Успешно», «В обработке», «С ошибкой» или «Проблемный» |

Внизу таблицы доступна пагинация: 25, 50, 75 или 100 записей на страницу.

### Просмотр частей пакета

1. Нажмите на идентификатор пакета в таблице.
2. На странице «Части пакета» изучите идентификатор пакета, его статус и таблицу частей:

   | Колонка | Описание |
   |---------|----------|
   | **№ части пакета** | Порядковый номер части |
   | **Идентификатор** | Идентификатор части |
   | **Статус** | Статус обработки части |

3. Нажмите на стрелку в строке части, чтобы развернуть её содержимое в формате JSON.

Если по заданным условиям пакетов не найдено, отображается сообщение «Нет результатов, подходящих под параметры поиска».
