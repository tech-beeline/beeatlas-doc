# Управление возможностями

**Назначение**: Создание бизнес-возможностей в системе.

## Возможности

- Создание бизнес-возможности
- Выбор родительской возможности: бизнес-возможности, домена или группы
- Указание владельца и ссылки на страницу с описанием

На странице нет списка возможностей и фильтров: доступны заголовок «Управление возможностями» и кнопка «Создать бизнес-возможность».

## Типы возможностей

В системе существуют два типа возможностей:

- **Бизнес-возможности (BC)** — возможности бизнес-уровня
- **Технические возможности (TC)** — возможности технического уровня

## Удаление возможностей (TC и BC)

Удаление возможностей доступно **только из дерева ФДМ** (раздел «Модели» → «ФДМ»). Удалять могут **только пользователи с ролью администратор**.

**Ограничения при удалении BC (бизнес-возможности):**
- BC можно удалить только если у него **нет дочерних BC или TC**
- Сначала необходимо удалить или переместить все дочерние возможности

**TC (технические возможности)** удаляются из дерева ФДМ при выборе соответствующей TC.

## Как использовать

### Создание бизнес-возможности

1. Перейдите в раздел "Консоль администратора" → "Управление возможностями".
2. Нажмите кнопку "Создать бизнес-возможность".
3. Заполните форму:

   - **Родительская возможность*** — начните вводить название и выберите бизнес-возможность, домен или группу.
   - **Краткое наименование*** — до 255 символов.
   - **Полное определение**.
   - **ФИО владельца возможности** — до 255 символов.
   - **Ссылка на страницу с описанием** — до 255 символов.

4. Нажмите кнопку "Создать бизнес-возможность".

После создания происходит возврат на страницу «Управление возможностями».
