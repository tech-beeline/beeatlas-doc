# Управление критериями

**Назначение**: Создание и редактирование критериев оценки возможностей.

## Возможности

- Просмотр списка критериев
- Поиск по критериям
- Создание и редактирование критериев
- Загрузка шаблона и импорт значений критериев

Критерии отображаются плоским списком: иерархии критериев нет.

## Основные элементы экрана

- **Поиск** — фильтрует таблицу по названию и коду критерия.
- **«Шаблон»** — скачивает шаблон `criteria.xlsx` для заполнения.
- **«Импорт значений критериев»** — открывает боковую панель загрузки файла.
- **«Создать критерий»** — открывает форму создания.
- **«Правила создания критерия»** — ссылка на инструкцию.

## Таблица критериев

| Колонка | Описание |
|---------|----------|
| **Критерий** | Название критерия |
| **Код** | Код критерия |
| **Действия** | Иконка редактирования |

## Создание критерия

1. Перейдите в раздел "Консоль администратора" → "Управление критериями".
2. Нажмите кнопку "Создать критерий".
3. Заполните форму:

   | Поле | Описание |
   |------|----------|
   | **Название\*** | Название критерия |
   | **Код\*** | Код из строчных латинских букв, цифр и символов. При редактировании недоступен |
   | **Настройка оси** | Чекбокс «Обратная ось», поля «Название минимальной точки оси\*» и «Название максимальной точки оси\*» |
   | **Метрика расчёта** | Один из вариантов: **Непрерывный** (поля «Порог\*» и «Шаг\*»), **Оценочный** (поле «Интервал\*») или **Дискретный** (поле «Интервал\*») |

4. Нажмите кнопку "Создать".

### Редактирование критерия

1. Нажмите иконку редактирования в строке критерия.
2. Внесите изменения. Код критерия изменить нельзя.
3. Нажмите кнопку "Сохранить".

> **Примечание:** при изменении параметров оси (интервал, шаг) существующая визуализация карты возможностей перестраивается под новые параметры для уже загруженных результатов расчёта.

## Импорт значений критериев

1. Нажмите кнопку "Импорт значений критериев".
2. Загрузите файл `.xlsx` размером до 100 МБ. Файл загружается сразу после выбора.
3. Нажмите «Готово».

Ход загрузки отображается в разделе [Импорт файлов](file_import.md).
