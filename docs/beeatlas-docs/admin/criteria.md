# Управление критериями

**Назначение**: Определение правил и условий для различных процессов.
<!-- ![apps](images/apps.png)-->
## Возможности

- Просмотр списка всех критериев
- Создание новых критериев
- Редактирование существующих критериев
- Управление иерархией критериев
- Просмотр детальной информации о критериях

## Как использовать

### Просмотр критериев

1. Перейдите в раздел "Консоль администратора " → "Критерии"
2. Используйте фильтры для просмотра критериев определенного типа
3. Просмотрите список критериев

### Создание нового критерия

1. Перейдите в раздел "Консоль администратора " → "Критерии"
2. Нажмите кнопку "Добавить критерий"
3. Заполните форму:
   - Название
   - Описание
   - Родительский критерий (если есть)
   - Дополнительные атрибуты
4. Сохраните критерий

### Управление иерархией

Критерии организованы в иерархическую структуру:
- Каждый критерий может иметь родительский критерий
- Каждый критерий может иметь дочерние критерии
- Используйте интерфейс для управления иерархией
