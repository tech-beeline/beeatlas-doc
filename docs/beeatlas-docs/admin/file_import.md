# Импорт файлов

**Назначение**: Загрузка данных в систему с использованием подготовленных шаблонов.

## Возможности

- Загрузка файлов `.xlsx` по шаблону
- Выбор типа файла: BC или TC
- Скачивание шаблонов для заполнения
- Просмотр загруженных файлов и их статусов

## Поддерживаемый формат

Импорт выполняется только из файлов `.xlsx` размером до 100 МБ. Файлы с другой структурой не загружаются — для загрузки данных используются шаблоны.

## Типы данных для импорта

В боковой панели «Импорт файла» доступны два типа файла:

- **BC** — бизнес-возможности;
- **TC** — технические возможности.

## Как использовать

1. Перейдите в раздел "Консоль администратора" → "Импорт файлов".
2. В блоке «Шаблоны для заполнения данных» скачайте нужный шаблон и заполните его.
3. Нажмите кнопку "Импорт файла".
4. Выберите тип файла: BC или TC.
5. Выберите файл `.xlsx` размером до 100 МБ. Загрузка начинается сразу после выбора файла.
6. Нажмите «Готово», чтобы закрыть боковую панель.
7. Статус обработки файла смотрите в блоке «Загруженные файлы».

## Блок «Шаблоны для заполнения данных»

В блоке отображаются доступные шаблоны. Кнопка скачивания сохраняет шаблон на компьютер.

## Блок «Загруженные файлы»

Таблица содержит колонки:

| Колонка | Описание |
|---------|----------|
| **Название** | Имя загруженного файла |
| **Формат** | Расширение файла |
| **Дата** | Дата загрузки |
| **Статус** | Состояние обработки файла |

Возможные статусы: «Загрузка», «Успешно», «Ошибка», «Проблемный», «Ошибка валидации».

## Обработка ошибок

При импорте возможны ошибки:

- неверный формат файла;
- ошибки в данных;
- ошибки валидации.

Статус файла отображается в блоке «Загруженные файлы».
