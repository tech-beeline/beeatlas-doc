# BeeAtlas - Пользовательская документация

Добро пожаловать в систему архитектурного моделирования **BeeAtlas**! Эта документация поможет вам освоить все возможности системы.

## О системе

BeeAtlas — это комплексная система для управления архитектурой предприятия, которая позволяет:
- Моделировать и анализировать бизнес-возможности
- Управлять технологическим стеком компании
- Отслеживать приложения и их архитектуру
- Работать с паттернами и антипаттернами разработки
- Вести проекты архитектуры решений и оценивать их
- Управлять подписками и уведомлениями
- Задавать вопросы AI-помощнику прямо на страницах портала
- Администрировать систему

## Навигация по документации

### Основные разделы

1. **[Модели](./models.md)** — работа с функционально-доменной моделью, технорадаром, картами возможностей и другими инструментами моделирования
2. **[CX (Customer Experience)](./cx.md)** — библиотеки CJ (Customer Journey) и BI (Business Interaction)
3. **[Проекты](./projects.md)** — проекты архитектуры решений, агент «Оценка», мастер оценки и Use Case
4. **[Профиль](./profile.md)** — управление заявками, подписками и экспортом данных
5. **[Админка](./admin.md)** — административные функции (доступно только администраторам)
6. **[Уведомления](./notifications.md)** — система уведомлений о изменениях
7. **[AI-помощник](./ai-assistant.md)** — чат с ассистентом по платформе, история диалогов, обратная связь по данным

## Основные возможности

### Для всех пользователей

- Просмотр и поиск по функционально-доменной модели
- Работа с технорадаром технологий
- Просмотр каталога приложений
- Работа с библиотеками CJ и BI
- Работа с проектами архитектуры решений и Use Case
- Управление подписками и уведомлениями
- Подача заявок на создание/изменение сущностей
- Общение с AI-помощником и жалобы на некорректные данные

### Для администраторов

- Управление пользователями и ролями
- Импорт данных из файлов
- Управление технологиями и возможностями
- Администрирование системы

## Как устроен интерфейс

**Главная страница** (логотип beeatlas в шапке) — точка входа в систему. На ней расположены:

- поле запроса к AI-помощнику — открывает чат в полноэкранном режиме с уже подставленным вопросом;
- блок «Моё пространство» — карточки «Мои приложения» и «Мои заявки» с переходом в соответствующие разделы профиля;
- блок «Сервисы» — карточки инструментов, сгруппированные по доменам: «Проектирование CX», «Архитектура решения», «Бизнес-архитектура», «Архитектура приложения», «Техническая архитектура».

**Левое меню** повторяет те же группы и ведёт сразу на нужный инструмент:

```
Проектирование CX
├── Библиотека CJ
└── Библиотека BI

Бизнес-архитектура
├── Поиск ФДМ
├── ФДМ
├── Карта возможностей
└── Каталог E2E-сценариев

Архитектура приложения
├── Каталог приложений
├── Каталог жизненных ситуаций
└── Аналитический отчет фитнес-функций

Архитектура решения
└── Проекты

Техническая архитектура
├── Каталог паттернов
├── Архитектура компании
└── Технорадар
```

В шапке переключаются основные разделы — **Модели**, **База знаний** и **Поддержка Cx**, — а также доступны тема оформления, уведомления и меню профиля.

## Ссылки в шапке

В шапке портала, помимо разделов, доступны ссылки на смежные ресурсы:

### Документация

Ссылка **Документация** ведёт на **портал документации** — единый ресурс по методологии ПТР (Проектирование Технического Решения) и системе BeeAtlas. Документация включает:

- Методологию проектирования технических решений
- Инструкции по настройке инструментов (VS Code, Structurizr, GitLab, CI/CD)
- Описание моделей, реестров и правил моделирования
- Пользовательскую документацию BeeAtlas

### WebIDE и плагин VARP

Ссылка **WebIDE** отображается в непроизводственных окружениях и открывает Visual Studio Code с установленным корпоративным плагином **VARP** (C4 Architecture As A Code). Плагин предоставляет:

- Редактирование архитектурных моделей в формате Structurizr DSL с подсветкой, подсказками и переходами
- Интеграцию с ArchOps: каталог архитектурных паттернов, каталог бизнес-возможностей, фитнес-проверки
- Предпросмотр диаграмм C4 и экспорт в SVG, draw.io и workspace JSON
- Работу без Java — в настольном VS Code и в браузере

Подробная настройка плагина описана в разделе [Настройка plugin](../Настройка%20plugin.md) документации ПТР. Актуальная версия плагина — 2.1.2, она не требует установки Java.
