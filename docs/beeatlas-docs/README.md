# BeeAtlas - Пользовательская документация

Добро пожаловать в систему архитектурного моделирования **BeeAtlas**! Эта документация поможет вам освоить все возможности системы.

## О системе

BeeAtlas — это комплексная система для управления архитектурой предприятия, которая позволяет:
- Моделировать и анализировать бизнес-возможности
- Управлять технологическим стеком компании
- Отслеживать приложения и их архитектуру
- Работать с паттернами и антипаттернами разработки
- Управлять подписками и уведомлениями
- Администрировать систему

## Навигация по документации

### Основные разделы

1. **[Модели](./models.md)** — работа с функционально-доменной моделью, технорадаром, картами возможностей и другими инструментами моделирования
2. **[База знаний](./database.md)** — архитектурный комитет, техническая политика и сервисные услуги
3. **[CX (Customer Experience)](./cx.md)** — библиотеки CJ (Customer Journey) и BI (Business Interaction)
4. **[Профиль](./profile.md)** — управление заявками, подписками и экспортом данных
5. **[Админка](./admin.md)** — административные функции (доступно только администраторам)
6. **[Уведомления](./notifications.md)** — система уведомлений о изменениях

## Основные возможности

### Для всех пользователей

- Просмотр и поиск по функционально-доменной модели
- Работа с технорадаром технологий
- Просмотр каталога приложений
- Работа с библиотеками CJ и BI
- Управление подписками и уведомлениями
- Подача заявок на создание/изменение сущностей

### Для администраторов

- Управление пользователями и ролями
- Импорт данных из файлов
- Управление технологиями и возможностями
- Администрирование системы

## Ссылки с главной страницы

С главной страницы BeeAtlas (раздел «Модели») доступны быстрые ссылки на дополнительные ресурсы:

### Документация

Ссылка на **портал документации** — единый ресурс по методологии ПТР (Проектирование Технического Решения) и системе BeeAtlas. Документация включает:

- Методологию проектирования технических решений
- Инструкции по настройке инструментов (VS Code, Structurizr, GitLab, CI/CD)
- Описание моделей, реестров и правил моделирования
- Пользовательскую документацию BeeAtlas

### WebIDE и плагин VARP

Ссылка на **WebIDE** — Visual Studio Code с установленным корпоративным плагином **VARP** (C4 Architecture As A Code). Плагин предоставляет:

- Редактирование архитектурных моделей в формате Structurizr DSL
- Интеграцию с ArchOps и корпоративным технорадаром
- Предпросмотр диаграмм C4
- Загрузку описаний возможностей из BeeAtlas

Подробная настройка плагина описана в разделе [Настройка plugin](../Настройка%20plugin.md) документации ПТР.

## Структура системы

Система организована в виде одностраничного приложения (SPA) с следующими основными разделами:

```
BeeAtlas
├── Модели
│   ├── Поиск возможностей
│   ├── ФДМ
│   ├── Технорадар
│   ├── Карта возможностей
│   ├── Каталог приложений
│   ├── E2E сценарии
│   ├── Архитектура компании
│   ├── Каталог паттернов
│   ├── Аналитический отчет фитнес-функций
│   └── Каталог жизненных ситуаций
├── База знаний
│   ├── Архитектурный комитет
│   ├── Техническая политика
│   └── Сервисные услуги
├── CX
│   ├── Библиотека CJ
│   └── Библиотека BI
├── Профиль
│   ├── Мои заявки
│   ├── Рецензирование
│   ├── Подписки
│   └── Экспорт
└── Админка (только для администраторов)
    ├── Пользователи
    ├── Роли
    ├── Импорт файлов
    ├── Импортированные данные
    ├── Технологии
    ├── Возможности
    ├── Staging (наблюдаемость и поиск)
    └── ...
```
